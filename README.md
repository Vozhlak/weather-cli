# 🌤️ Weather CLI

Интерактивное консольное приложение на Go для просмотра текущей погоды и прогнозов через [Open-Meteo](https://open-meteo.com/). Приложение работает прямо в терминале, кэширует ответы и позволяет менять город без перезапуска.

## ✨ Возможности

- текущая погода: температура, ощущаемая температура, условие, ветер, влажность, давление, видимость и осадки;
- почасовой прогноз на 12 часов;
- прогноз на 7 дней;
- интерактивное переключение экранов без перезапуска;
- смена города с проверкой через API;
- сохранение города по умолчанию в `config.yaml`;
- TTL-кэш с разным временем жизни для разных типов прогноза;
- принудительное обновление через `R` с защитой от слишком частых запросов;
- повторные попытки сетевых запросов;
- цветной вывод и погодные иконки.

## 🧰 Требования

- Go 1.25 или новее;
- подключение к интернету;
- терминал с поддержкой UTF-8 и ANSI-цветов.

Приложение использует Open-Meteo Geocoding API и Forecast API. API-ключ не требуется.

## 🚀 Установка и запуск

```bash
git clone https://github.com/Vozhlak/weather-cli.git
cd weather-cli

go mod download
go run ./cmd/weathercli
```

Сборка бинарного файла:

```bash
go build -o weathercli ./cmd/weathercli
./weathercli
```

Для Windows:

```powershell
go build -o weathercli.exe ./cmd/weathercli
.\weathercli.exe
```

## ⚙️ Конфигурация

При первом запуске приложение попросит указать город и сохранит его в корне проекта:

```yaml
default_city: Moscow
```

При следующем запуске этот город будет использован автоматически. Изменить его можно командой `C`.

`config.yaml` содержит пользовательские настройки и добавлен в `.gitignore`, поэтому его не следует коммитить в репозиторий.

## 🎮 Управление

| Команда | Действие |
|:---:|---|
| `0` | Текущая погода |
| `1` | Почасовой прогноз на 12 часов |
| `2` | Прогноз на 7 дней |
| `C` | Сменить город |
| `R` | Принудительно обновить текущий экран |
| `Q` | Выйти |

Команды нечувствительны к регистру. После открытия экрана данные сначала ищутся в кэше. Если запись отсутствует или истекла, приложение обращается к API. Команда `R` игнорирует кэш для текущего экрана, но ограничена минимальным интервалом между обновлениями.

## 🧱 Используемые технологии

- Go;
- `bufio.Reader` для построчного интерактивного ввода;
- `context.Context` для таймаутов и отмены запросов;
- Open-Meteo Geocoding API и Forecast API;
- YAML через `gopkg.in/yaml.v3`;
- стандартные HTTP, JSON, sync и time;
- TTL-кэш с потокобезопасным доступом;
- ANSI escape sequences и Unicode-иконки для UI.

## 🧪 Кэширование

| Данные | TTL |
|---|---:|
| Текущая погода | 10 минут |
| Почасовой прогноз | 30 минут |
| Прогноз на 7 дней | 60 минут |

Разные TTL позволяют чаще обновлять быстро меняющиеся текущие данные и не отправлять лишние запросы для долгосрочного прогноза.

## 🛡️ `.gitignore`

В репозиторий не должны попадать:

- бинарные файлы (`weathercli`, `*.exe`);
- пользовательская конфигурация (`config.yaml`);
- IDE-файлы (`.idea/`, `.vscode/`);
- временные файлы, логи, coverage и системные файлы.
